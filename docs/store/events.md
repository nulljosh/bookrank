# In-app events

An in-app event is a card on the App Store and in search, for something that happens in the app on a date. Kernel runs one per major release that people can feel, made in App Store Connect under In-App Events, reviewed with the version or on its own.

Each needs a name (30 characters), a short description (50), a long description (120), a 1920x1080 card and a 1080x1920 card from the real app screens in `ios/fastlane/screenshots/en-US`, a start and an end, and the badge.

| When | Badge | Name | Short description |
|---|---|---|---|
| The release with the four languages | New Season | Kernel speaks your language | French, Spanish and German, narration too |
| The first Monday of a month | Challenge | One chapter a day | Five minutes a day for a week, with a streak |
| A big import (Goodreads, Kindle, EPUB) | Major Update | Bring your whole shelf | Goodreads, Kindle and EPUB in a minute |

Keep the names true to what the live version does; an event for a feature still in review waits for it.
