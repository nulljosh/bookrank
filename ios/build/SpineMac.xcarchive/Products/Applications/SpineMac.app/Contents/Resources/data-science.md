# Chapter 20: Ten Free or Low-Cost Data Science Tools and Applications

Part of "The Part of Tens" — a rundown of ten free/low-cost SaaS and desktop tools covering the full data science workflow: scraping, exploration, machine learning, visualization, and infographics. Framed as a starter toolkit that doesn't require deep technical investment.

## Scraping, Collecting, and Handling Data Tools

### Sourcing and aggregating image data with ImageQuilts
ImageQuilts (from Stanford) lets you compile grids of related images pulled from a Google image search into a single collage, useful for quick visual/content analysis of image sets (e.g. logo or aesthetic comparisons) without manual downloading.

### Wrangling data with DataWrangler
DataWrangler (developed by Stanford/University of Washington) is a browser-based tool for cleaning and reshaping messy datasets — transposing, splitting columns, handling missing values — without writing code.
**Photo:** Screenshot showing a colorful DataWrangler interface with multiple dataset visualizations/thumbnails in a grid.

## Data-Exploration Tools

### Getting up to speed in Gephi
Gephi is an open-source network-graph visualization tool, good for exploring relationships/connections (e.g. social networks) as node-and-edge graphs, useful for spotting clusters and central nodes in relational data.
**Photo:** Screenshot of a Gephi network graph with connected circular nodes.

## Machine Learning Tool

### Machine learning with the WEKA suite
WEKA (University of Waikato) is a well-established, free Java-based GUI application offering many machine learning algorithms for classification, clustering, and pattern discovery — good for experimenting without writing ML code from scratch.
**Photo:** Screenshot of the WEKA interface showing a graph/plot output.

## Data Visualization Tools

### Designing data visualizations by RStudio
RStudio is a free IDE for the R programming language, widely used for statistical analysis and both code-based and dashboard (Shiny) visualizations.

### Getting Shiny by RStudio
Shiny (an R package/framework by RStudio) lets you build interactive web-based dashboards and data apps using R code, without needing separate front-end web development skills.

### Mapmaking and spatial data analytics with CARTO
CARTO is a mapping/geospatial analytics platform letting non-GIS-experts build interactive maps from spatial datasets, popular for visualizing location-based data (e.g. choropleth maps, geographic distributions).
**Photo:** Screenshot of a CARTO map showing a colored/textured geographic region visualization.

### Talking about Tableau Public
Tableau Public is a free version of the popular Tableau BI/visualization software, letting users publish interactive dashboards and charts publicly (with some data-size and privacy limitations vs. paid Tableau).
**Photo:** Screenshot of a Tableau Public dashboard with dark background and colored data visualization.

### Using RAWGraphs for web-based data visualization
RAWGraphs is a free, open-source web app for creating unique/unconventional chart types (e.g. circle packing, alluvial diagrams) from CSV data without coding — good for going beyond standard bar/line/pie charts.
**Photo:** Screenshot of a RAWGraphs circle-packing visualization.

## Infographics Tools

### Communicating with infographics
A section framing infographics as combining data visualization with graphic design for broader audience communication — contextual to a chosen theme/story rather than raw exploratory charts.

### Making cool infographics with Infogram
Infogram is a drag-and-drop infographic and dashboard builder offering templates, charts, and interactive graphics for web publishing.

### Making cool infographics with Piktochart
Piktochart is another web-based infographic tool for building bar/line/area/scatter/pie charts, matrices, pyramids, gauges, and more into polished visual layouts.
**Photo:** Screenshot of a Piktochart-made bar chart titled "In-County Moving," showing how many people per state changed addresses within the same county (Figure 20-8).

### Other tools mentioned briefly
Datawrapper (used by The New York Times, Wired, Fortune for charts/maps/tables) and Mapbox (for high-quality geographic data and custom shapefiles for GIS).

## Key takeaways
- The chapter is explicitly a curated top-10 "starter list," acknowledging many more tools exist beyond it.
- Coverage spans the full pipeline: scrape/collect (ImageQuilts, DataWrangler) → explore (Gephi) → model (WEKA) → visualize (RStudio/Shiny, CARTO, Tableau Public, RAWGraphs) → communicate (Infogram, Piktochart).
- Nearly all tools are free or freemium, reinforcing the book's theme that data science doesn't require expensive enterprise software to get started.
