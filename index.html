Install it anywhere.

iPhone, iPad and Mac get the native app. On Windows, Linux and Android it installs straight from the browser. No store, no download, no runtime. It gets a real window, its own icon, and keeps working offline.

Windows

Open the web app in Edge or Chrome, then Install Bookrank from the address bar. It lands in the Start Menu like any other app.

Open & install →

Android

Open the web app in Chrome, then Add to Home screen. Full screen, no browser chrome, works offline.

Open & install →

Linux

Same as Windows. Install the web app from Chrome or Chromium and it runs in its own window.
